# مهام العائلة — المصدر

PWA عربي: قائمة مشتريات مشتركة، ومهام ومواعيد مع تذكير، وصفحة «مهامي».
يعمل على نفس مجموعة «ختمة العائلة» و«أذكار العائلة» (نفس الرمز والأعضاء والرمز السري).

- app.js — منطق التطبيق (يستبدل البناء __DB__ و__VAPID__)
- app.css — التنسيق (هوية أذكار العائلة)
- privacy.html — سياسة الخصوصية
- icon/ — الأيقونات
- build.py — يولّد مجلد /tasks/ ويحدد رقم الإصدار (VER). شغّله: `python3 tasks-src/build.py`

البيانات في Firebase تحت `/k/<code>/tk`:
- `shop/<id>`: `n` الاسم، `by` من أضافه، `c` وقت الإضافة، `b` من اشتراه، `bt` وقت الشراء
- `tasks/<id>`: `t` العنوان، `d` التاريخ، `tm` الوقت، `at` وقت الموعد (ms)، `rm` التذكير بالدقائق قبله (-1 بلا)،
  `ra` وقت التذكير (ms)، `rs` آخر `ra` أُرسل، `as` المُسنَد إليهم، `n` ملاحظة، `by` و`c`، `dn` من أنجزها و`dt`
- `subs/<k>`: اشتراكات الإشعارات (`m` = الفرد)

الأعضاء تُقرأ من `/k/<code>/members` (تُدار من «ختمة العائلة»).
التذكيرات: tasks-push/send.js عبر .github/workflows/tasks-notify.yml كل 15 دقيقة.
لا يُكتب رمز المجموعة في أي ملف منشور؛ يصل فقط عبر رابط الدعوة (#a=) ويُحفظ في الهاتف.
