# أذكار العائلة — المصدر

نسخة احتياطية من ملفات المصدر (قبل البناء):
- app.js — منطق التطبيق (يحوي المتغيرات __DB__ و__VAPID__ و__ADHKAR_...__ التي يستبدلها البناء)
- app.css — التنسيق
- adhkar.json — نصوص الأذكار (القرآن برواية ورش من مجمّع الملك فهد)
- build.py — يولّد index.html وapp.js وapp.css وsw.js ويرفع رقم الإصدار (VER)

البناء يحتاج ملفات خارج المستودع: tools/fonts.css، push/vapid.json (المفتاح العام)، مجلد icon/.
الناتج المنشور هو مجلد /adhkar/ في هذا المستودع، وهو الأصل الحي: يمكن التعديل عليه مباشرة عند الحاجة،
مع رفع اسم الكاش في sw.js (ad-vNN) ورقم الإصدار في index.html (app.js?v=NN) ليتحدّث عند المستخدمين.
